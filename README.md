# PaperTrans - 论文翻译网站

PaperTrans是一个专为学术研究人员设计的论文翻译工具，可以帮助用户快速翻译学术论文，并提供双栏对照阅读功能。

## 功能特点

- **双栏对照翻译**：原文和译文并列展示，方便对比阅读
- **PDF文件上传**：支持直接上传PDF格式论文
- **URL解析**：支持输入论文URL自动获取内容
- **智能翻译**：基于先进AI模型的高质量翻译
- **段落对应**：悬停高亮显示对应的原文和译文段落
- **多种格式导出**：支持PDF、Word等格式导出
- **翻译历史**：自动保存翻译历史，随时查阅

## 技术实现

- 前端：HTML5, CSS3, JavaScript (原生)
- 响应式设计：适配各种设备屏幕尺寸
- 界面风格：简洁、现代、清爽的UI设计

## 项目结构

```
paper-translator/

├── images/            // 图片资源
├── index.html         // 首页
├── translate.html     // 翻译结果页面
└── README.md          // 项目说明
```

## 安装使用

1. 克隆代码仓库：
   ```
   git clone https://github.com/yourusername/paper-translator.git
   ```

2. 打开index.html即可在浏览器中查看网站
